# Hrudhayam LIVE 🎵

A complete seat allocation, e-ticketing, and door check-in management system built for the Hrudhayam LIVE charity musical concert by the Rotary Club of Aarch City Madras.

## Features
- **Seat Mapping & Allocation**: Assign specific seats to guests and team members.
- **Group Ticketing**: Merge multiple seats under a single pass code and generate a unified PDF E-Ticket.
- **Check-in Scanner**: Built-in QR scanner for door check-ins with duplicate prevention.
- **Mass Emailing**: Send E-Tickets to guests in bulk via integrated mail queues.
- **Audit Logging**: Comprehensive tracking of all database modifications by users.

## Tech Stack
- Next.js (App Router)
- Supabase (PostgreSQL, Auth)
- Tailwind CSS & shadcn/ui
- React PDF & QR Scanner
